# kex-seamless-auto-fix
Fix broken KeX Seamless Mode in Kali Linux WSL2 with one click. Automatically resolves missing visuals, 0 client errors, and slow file manager launch. Includes VcXsrv fixes, .Xauthority config, XFCE session startup, and Windows firewall rules.

## Kali Linux on a Galaxy S25 Ultra

[`android/`](android/) installs Kali Linux on a Samsung Galaxy S25 Ultra without root: Kali NetHunter Rootless with the full image and the default Kali tools, plus a NetHunter KeX desktop that also works on a monitor with Samsung DeX. See [android/README.md](android/README.md).
